Local-first · Không cần tài khoản
Giới hạn quan trọng: trang này không thể tự đọc dữ liệu riêng tư của mọi game hoặc localStorage của website khác. Bạn có thể nhập/xuất file save JSON tại đây. Muốn đồng bộ trực tiếp với từng game, game đó cần tích hợp API hoặc cơ chế kết nối với Save Hub.
