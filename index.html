RPG Save Hub

Sao lưu dữ liệu trình duyệt để chuyển save giữa PC và mobile

Quan trọng: trang này chỉ đọc được dữ liệu của https://w7lio.github.io khi mở trên đúng origin đó. Vì các game trong cùng origin dùng chung vùng lưu trữ trình duyệt, công cụ có thể sao lưu localStorage và IndexedDB của origin hiện tại — không thể chỉ đọc riêng một thư mục game. File backup có thể chứa dữ liệu của nhiều game trên cùng origin; đừng chia sẻ công khai.

1. Quét dữ liệu trên trình duyệt này

Hãy mở trang này từ GitHub Pages rồi bấm quét. Trên thiết bị đích, hãy mở từng game ít nhất một lần trước khi import để game khởi tạo vùng lưu trữ.

—Mục localStorage
—Database IndexedDB
—Bản ghi IndexedDB
Chưa quét dữ liệu.

2. Import backup từ thiết bị khác

Chọn file JSON đã export trên thiết bị nguồn. Công cụ sẽ nhập các khóa localStorage và bản ghi IndexedDB tương ứng. Các khóa trùng sẽ được ghi đè; dữ liệu khác được giữ lại.

Chưa import.

Quy trình chuyển PC ↔ mobile

  1. Trên PC, mở game và lưu trong game như bình thường.
  2. Mở Save Hub ở cùng domain, bấm Quét, rồi Export backup JSON.
  3. Gửi file JSON sang mobile bằng cách riêng tư, chẳng hạn cáp USB hoặc dịch vụ lưu trữ cá nhân.
  4. Trên mobile, mở đúng game và tạo/khởi tạo save nếu cần; sau đó mở Save Hub cùng domain.
  5. Chọn file backup, tích xác nhận và bấm Import backup. Tải lại game rồi kiểm tra save.

Khuyến nghị: export backup trên thiết bị đích trước khi import. Nếu game dùng cơ chế lưu riêng, plugin tùy chỉnh hoặc IndexedDB không tương thích, việc chuyển có thể không khôi phục được hoàn toàn.

Dữ liệu chỉ được xử lý trong trình duyệt; trang này không gửi backup lên máy chủ. GitHub Pages chỉ lưu mã nguồn trang, không lưu file backup của bạn.
